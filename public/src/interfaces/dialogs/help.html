Getting Started

Viritura is an MNX-based music notation editor. Create scores, add notes by clicking the staff or via note input, and edit with keyboard shortcuts.

  1. Press N to enter Note Input Mode
  2. Pick a duration from the toolbar (or press 1–8)
  3. Click the staff where you want the note, or type A–G
  4. Press N or Esc to exit note input
  5. Click any note to select and edit it
